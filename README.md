# DS-1 Superlaser Command Console 🔴

A totally safe and bug-free Death Star control panel application built for the Galactic Empire.

> "You may fire when ready." — Grand Moff Tarkin

## Quick Start

```bash
pip install -r requirements.txt
python app.py
```

Then open http://localhost:2187

**Login:** `tarkin` / `deathstar2024`

## Features

- 🎯 Planet targeting array with search
- ⚡ Reactor power management
- 💥 Superlaser firing sequence with countdown
- 👤 Crew station monitoring
- 📋 Operations log

## Stack

- **Backend:** Python / Flask
- **Database:** SQLite
- **Frontend:** HTML / CSS / JavaScript

## Architecture

```
app.py          — Flask routes and API endpoints
database.py     — Database setup, seeding, and helpers
templates/      — Jinja2 HTML templates
static/css/     — Styles (dark sci-fi control panel theme)
static/js/      — Frontend logic
```
